# Seguimiento Post-CAPA · Blue Medical

Dashboard de seguimiento de nuevos ingresos después de la capacitación CAPA.

## Importante antes de publicar

- **Fuera de Claude, los datos se guardan solo en el navegador de cada persona.** El guardado compartido funciona únicamente en la versión de claude.ai. En GitHub Pages, lo que registra cada usuario queda en su propia computadora y navegador y no lo ven los demás.
- **No subas datos reales de colaboradores** (evaluaciones, observaciones, ventas) a este repositorio. Un sitio de GitHub Pages es público en internet, aunque el repositorio sea privado, salvo en planes empresariales con control de acceso.
- El archivo incluye datos de ejemplo ficticios. Se pueden borrar desde **Colaboradores → Eliminar datos de ejemplo**.

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y este `README.md` con **Add file → Upload files** y confirma con **Commit changes**.
3. Ve a **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. Después de uno o dos minutos, GitHub mostrará la dirección del sitio, con la forma `https://<tu-usuario>.github.io/<nombre-del-repositorio>/`.

## Abrirlo sin publicar

También puedes abrir `index.html` con doble clic en Chrome. Funciona igual, con los datos guardados solo en ese navegador.
